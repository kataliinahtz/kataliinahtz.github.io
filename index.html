02 / BEFORE YOU BEGIN

动手前的准备

重装不是修复单个文件，而是重新部署系统。给自己留好恢复和重新连接的余地。

  • 备份数据保存网站文件、数据库和配置，并确认备份可以读取。快照或自动备份是否可用，以面板显示为准。
  • 确认面板入口确保可以登录账号并找到对应 VPS 的 KiwiVM 控制面板。
  • 准备连接信息记录服务器 IP，并准备好 SSH 客户端；安装后再次核对端口和凭据。

03 / KIWIVM

在控制面板中重装 Linux

以面板中的操作流程为线索。界面名称和可用系统版本请以实际显示为准。

01

进入控制面板

登录搬瓦工账号，在 Services → My Services 中找到目标 VPS，进入 KiwiVM Control Panel。

02

停止服务器

在 Main Controls 查看运行状态。如果服务器正在运行，选择 Stop 并等待停机。

03

选择系统镜像

打开 Install new OS，从列表中选择需要的版本，例如可用的 Ubuntu 或 Debian 镜像。

04

确认并安装

仔细阅读数据删除提示，确认备份后勾选同意项，点击 Reload 开始安装。

05

保存新的连接信息

安装完成后，妥善保存显示的密码等凭据，并核对面板中的 SSH 端口，再尝试连接。

04 / ADVANCED

关于 DD 安装

DD 的核心是把镜像直接写入磁盘。它提供了自定义系统的另一种思路，但不是普通面板重装的快捷替代。

什么时候考虑？

当面板提供的 Linux 镜像不满足需求，或需要研究其他自定义系统时，可以先确认虚拟化环境、镜像兼容性和恢复方式。Windows 属于这类需求的背景之一，并不意味着特定安装方式一定可用。

需要注意什么？

写入会覆盖磁盘数据；镜像与脚本的来源、引导配置和安装后的访问方式都需要自行判断。使用可信来源，提前备份，并在安装后检查和更改默认凭据。

05 / AFTER INSTALLATION

重新连接与排查

系统安装完成只是起点。连接前先核对新的信息，不要沿用旧配置。

SSH 连接不上？

检查 KiwiVM 中显示的 SSH 端口、服务器地址、用户名和密码是否正确；再检查系统服务状态与防火墙设置。

找不到想要的系统？

先查看面板当前提供的镜像。自定义镜像涉及额外的兼容性与安全判断，适合熟悉系统安装和恢复的用户。

重装能改变线路吗？

不能将两者视为同一件事。重装主要更换磁盘上的系统；套餐和网络线路的选择需要另行考虑。
